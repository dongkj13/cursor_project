现在也在做 Reasoning 的一些做法

标准范式是输入到齐再写完整 CoT。实时交互要把思考叠进仍在走的时间轴： 用户还在说、自己还在说、或文本还在流进来。 下面按时间窗整理当前做法，而不是再列一篇 o1/R1 综述。

方法卡片

边听边想QC 触发DPO

Shih et al. · Think while Listening

Moshi 三流。用 Question Completeness ζ(p) 找语义拐点，把文本 CoT 左移到用户还在说的时候；Length-DPO 再压 endpoint 后静默。文本 CoT 约 2.4× 口语推理，延迟可降约 70%。

arXiv:2510.07497

边听边想固定 chunkagent

SHANKS

约 4s 一块音频就写一段 unspoken CoT。不只为了更快回答：听用户讲题时可更准地打断（+37.1%），56.9% 的 tool call 发生在用户说完之前。

arXiv:2510.06917 · 项目页

边听边想控制器DAPO

wait / think / answer

Qwen2.5-Omni 上学何时外化短状态。只优化最终答案会变成一直 wait。六奖励 DAPO：SRQA 67.6%→70.3%，并把 endpoint 后 final-think 从 10.44 压到 8.99 token。

arXiv:2605.27190

边听边想结构化节点全双工

Chronological Thinking

听的阶段不要再预测 silence，改成 entity/intent/action/knowledge/logic 节点。思考摊在 listening window，用户停口立刻停想。轻量会话，不是长数学 CoT。

arXiv:2510.05150

边听边想latent零延迟

FLAIR · Silent Thought

隐状态递归回灌，ELBO 对齐非因果专家，无需写出 CoT。前向即思考，延迟约 0，后续词更好改假设；代价是思考不可读、难驱动工具。

arXiv:2603.17837

边听边想级联语义触发

LTS-VoiceAgent

Dynamic Semantic Trigger 丢掉无信息片段；后台 Thinker 维护可修订状态，前台 Speaker 投机说。适合已有 ASR–LLM–TTS、不想换端到端底座。

arXiv:2601.19952

边说边想chunk 交织

STITCH

说一块、想下一块：播放第 N 块时用 GPU 空闲写 unspoken CoT。延迟对齐「不思考」基线，数学约 +15%。推理慢于播放就会卡。

arXiv:2507.15375 · 项目页

边说边想token 级

Mini-Omni-Reasoner

silent reasoning 与 spoken token 局部对齐交织；Thinker–Talker 只把回复送进合成。Spoken-MQA 算术 +19.1%。数据：SPOKEN-MATH-PROBLEMS-3M。

arXiv:2508.15827

边说边想双脑

Mind-Paced Speaking

Formulation Brain 持续产 think，Articulation Brain 先开口再吃后续思考。零延迟配置 Spoken-MQA 92.8%。真正并行，不是单序列切模式。

arXiv:2510.09592

边说边想共情

ReEmpathy

块交织用于情感自评：想的是上一句共情是否合适，再改下一句。说明「也做 reasoning」不必是算术推导。

见音频推理综述 §V-B2

边读边想并行 KV

StreamingThinker

文本流上因果 mask + 独立位置编码 + 并行 KV，读的时候就开始想。相对 batch thinking：开想等待约 -80%，出答案延迟约 -60%。

arXiv:2510.17238

边想边答RL

Apple Interleaved Reasoning

用 PPO/GRPO 训练多跳问答交错输出中间结论。TTFT 平均降 80%+，Pass@1 最高约 +19.3%。交错不一定要语音。

Apple ML

披露策略单流

SxS · When to Think, When to Speak

单流自回归里学习何时把私有推理变成对外文本：有依据才披露，避免为了 TTFT 灌 filler。

arXiv:2605.03314

各自会在哪死

边听边想消灭的是 endpoint 后等待，但短问句窗口不够，最后几个词改条件会让已写下的离散 CoT 作废。边说边想不依赖用户话有多长，但推理慢于播放就会口吃，也解决不了「用户还在说就要动手」。更完整的系统几乎一定是听窗预热 + 说窗藏剩余 CoT + 错误假设可回滚。
